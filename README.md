# Happy Diwali — Fireworks Greeting

A responsive single-page Diwali greeting with a dark cinematic background, outlined headline, neon greeting button, and colorful animated fireworks.

## Features
- Animated fireworks created with the HTML Canvas API
- Continuous random fireworks in multiple colors
- Click or tap anywhere to launch a firework
- Greeting button launches a burst of fireworks
- Responsive layout for desktop and mobile
- No dependencies or build tools required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Alternatively, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Enable GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Click **Save**.

After GitHub Pages finishes deploying, the site should be available at:
https://nitesh-datascience.github.io/Happy-Diwali/

## Files
- `index.html` — page structure
- `style.css` — layout, typography, glow and responsive styles
- `script.js` — canvas fireworks animation
